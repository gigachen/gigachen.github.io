# gigachen.me

A dependency-free personal website for GitHub Pages.

## Preview

Run `python3 -m http.server 8000` in this directory, then open `http://localhost:8000`.

## Publish

The existing `CNAME` file points GitHub Pages at `gigachen.me`. In repository Settings → Pages, select **Deploy from a branch**, `main`, and `/ (root)`. The custom domain also needs GitHub Pages DNS records.

Edit page copy and project links in `index.html`; edit appearance in `styles.css`.
